# Venera Prime 2.8.2

## 本次更新

- **取消下载后清理残留 #60**（@JieZhiF）：取消时会等正在写入的文件结束，清理本次任务创建的内容，保留原有页面。刷新本地库时会跳过带有未完成下载标记的目录。此前留下的目录可在「设置 → 应用 → 清理已放弃的下载」中选择并确认清理。
- **Android 授权目录续传 #59**（@JieZhiF）：使用系统文件选择器授权的目录时，恢复下载会在后台按章节批量读取文件名和大小，减少逐页查询造成的界面停顿。空文件和标记为失败的页面会重新下载。
- **阅读页边距实时预览 #57**（@suppermanzero）：拖动页边距滑块即可看到当前页面宽度变化，瀑布流也会应用新边距。高度较小的横屏下，页边距与进度控件并排显示。
